# TechStore Return Policy

1. Returns apply to delivered (or shipped) orders.
2. `final_sale` items are ineligible for preference returns.
3. Defective products remain eligible even if marked `final_sale`.
4. Electronics returned more than 7 days after delivery require inspection.
5. Return reason must be one of: defective_product, wrong_item, customer_preference, missing_parts, other.
